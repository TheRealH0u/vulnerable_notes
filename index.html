O projektu

Vulnerable Notes je poučna spletna aplikacija, zasnovana za demonstracijo varnostnih ranljivosti v modernih spletnih aplikacijah. Projekt služi kot učna platforma za razumevanje različnih varnostnih groženj in pravilnih praks pri razvoju varnih aplikacij.

Tehnologije

Python/Flask Vue.js Docker GitHub Actions PostgreSQL

Lastnosti

  • Uporabniška registracija in avtentikacija
  • Ustvarjanje in upravljanje osebnih zapiskov
  • RESTful API arhitektura
  • Containerizirana aplikacija z Docker
  • Avtomatsko testiranje z GitHub Actions
  • CI/CD pipeline z deployment na različna okolja
  • Demonstracija XSS in drugih varnostnih ranljivosti

Cilji projekta

Glavni cilj projekta je ponuditi praktično okolje za učenje o:

  • Varnostnih ranljivostih v spletnih aplikacijah
  • Pravilni implementaciji avtentikacije in avtorizacije
  • Sodobnih DevOps praksah (CI/CD, containerizacija)
  • Testiranju in zagotavljanju kakovosti kode
